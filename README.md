# Sentiment Analysis using NLP 🧠📊

## 📌 Project Overview

This project performs **Sentiment Analysis** on textual data using **Natural Language Processing (NLP)** techniques.  
It classifies the sentiment of a given piece of text (e.g., reviews, tweets, or comments) as **Positive**, **Negative**, or **Neutral**.  
The project demonstrates **text preprocessing**, **feature extraction**, and **machine learning-based classification**.

---

## 🚀 Features

- ✅ Text preprocessing:
  - Lowercasing  
  - Punctuation removal  
  - Stopwords removal  
  - Stemming/Lemmatization  

- ✅ Vectorization using:
  - **TF-IDF**
  - **CountVectorizer**

- ✅ Sentiment classification using ML models:
  - Logistic Regression  
  - Naive Bayes  
  - Support Vector Machine (SVM)

- ✅ Evaluation Metrics:
  - Accuracy  
  - Precision  
  - Recall  
  - F1 Score

- ✅ Visualization:
  - Word frequency distribution  
  - Sentiment distribution pie/bar charts
